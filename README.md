# Perfect Power New Asana - Task Management

Standalone task management page to replace Asana with bidirectional sync during transition period.

## Project Structure

- `docs/` - HTML interface and documentation
- `scripts/` - Python sync automation scripts
- `.github/workflows/` - GitHub Actions for scheduled syncs
- `data/` - JSON data storage for tasks
